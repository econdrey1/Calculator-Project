# Calculator-Project
I created this Calculator program as part of Day 10 of my 100 Days of Python course. The program allows users to perform basic math operations like addition, subtraction, multiplication, and division.

The main goal of this project was to get more comfortable using Python functions, dictionaries, loops, and conditional statements. I also wanted to learn how to make a program that allows users to continue calculating without having to restart it every time.

How the Program Works

The program asks the user to enter their first number.

The user chooses a math operation: addition, subtraction, multiplication, or division.

The program asks for a second number.

The calculator performs the selected operation and displays the answer.

The user can choose to continue calculating with the previous answer.

If the user wants to start over, the calculator clears the screen with blank lines and begins a new calculation.

Python Concepts I Used

Functions: Performs different mathematical operations.

Dictionaries: Connects math symbols to their corresponding functions.

While Loops: Allows users to continue calculating with previous results.

For Loops: Displays the available mathematical operations.

If/Else Statements: Determines whether to continue calculating or start over.

Variables: Stores numbers, calculations, and results.

User Input: Allows users to enter numbers and select operations.

Recursion: Restarts the calculator by calling the calculator() function again.

How to Run the Program

Download or clone this repository.

Make sure Python is installed on your computer.

Open the project in PyCharm or another Python editor.

Make sure main.py and art.py are in the same folder.

Run main.py.

Enter your numbers and choose the operation you want to perform.

Continue calculating with your previous answer or start a new calculation.

What I Learned

While working on this project, I learned how to create separate functions for different mathematical operations and connect them using a dictionary. I also got more practice using loops and conditional statements to control how a program works.

One thing I learned was how to take the result of a previous calculation and use it in another calculation. I also learned how a function can call itself to restart a program.

This project helped me improve my problem solving skills and better understand how functions, dictionaries, and loops can work together to create an interactive program.
